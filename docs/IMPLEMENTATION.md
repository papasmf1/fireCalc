# fireCalc 구현 보고

## 완료한 내용

- shadcn/ui 기반 컴포넌트와 Recharts 의존성, zod, Vitest를 구성했습니다.
- `src/lib/data`에 Zod 계약 스키마와 실제 `data/` 우선·fixture fallback 로더를 추가했습니다.
- `src/lib/sim`에 월 단위 적립 백테스트, 환율 모드, 리밸런싱 옵션 인터페이스, FIRE 목표액, 세금 모델, seed 고정 몬테카를로, MDD·분위수 계산을 순수 함수로 구현하고 테스트했습니다.
- `/`, `/simulate`, `/etfs`, `/api/fx`를 한국어·원화 기본 UI로 구현했습니다. 모바일 레이아웃, 다크모드 토큰, 면책 푸터를 포함합니다.
- `npm run test`, `npm run lint`, `npm run build` 스크립트와 데이터 수집 스크립트 연결 명령을 등록했습니다.

## 남은 이슈

- Haiku가 수집 중인 `data/`가 아직 없는 환경에서는 fixture가 표시됩니다. 실제 파일이 생기면 같은 경로를 자동으로 우선 사용합니다.
- 차트는 의존성 및 차트용 UI 컴포넌트를 설치했지만, 현재 화면에서는 의존성 없는 막대형 시각화를 사용합니다. 실제 시계열 데이터가 들어오면 Recharts 기반 상세 차트로 확장할 수 있습니다.
- `SPYQ`의 실존 여부와 실제 세금·환율은 수집 데이터와 함께 검토해야 합니다.

## 리뷰 반영

- C-1: 대시보드·ETF 비교·시뮬레이터가 실제 `data/etf/*.json`, `data/fx/usdkrw-monthly.json`, `summary.json`을 읽고 `buildMonthlyReturns`·`runBacktest`·`monteCarlo`에 연결되도록 수정했습니다.
- C-2: 과거 환율 모드의 초기 원금도 첫 사용 월 환율로 환전하도록 수정했습니다.
- C-3: ETF별 USD 보유가치를 추적하고, 적립은 목표 비중으로 배분하며, 연 1회에만 리밸런싱하도록 수정했습니다.
- C-4: 실제 summary 구조(USD/KRW, periods, 객체형 best/worst year)에 맞춰 Zod 스키마를 수정했습니다. 실제 파일 파싱 실패는 로그와 화면 오류로 노출하고, fixture는 개발 환경의 파일 부재 때만 사용합니다.
- C-5: ETF·환율 날짜의 공통 교집합만 사용하고, 실제 사용 개월 수를 화면에 표시했습니다. SCHD·SPYQ 단기 데이터와 SPYQ 2배·분기 리셋 경고, VOO/QQQM proxy 안내를 추가했습니다.
- I-1: 연도별 실현이익·배당에 연 250만원 공제를 적용하는 `taxByYear`를 추가했습니다.
- I-2: 몬테카를로에 적립기와 은퇴 후 인출기를 함께 포함하고, 월수익률을 소수 단위로 통일했으며 물가상승을 인출액에 반영했습니다.
- I-3: FIRE 목표액에 은퇴 시점 물가상승과 인출률을 반영하도록 확장했습니다.
- I-4: 실제 데이터 스키마, 초기 환전, 리밸런싱, 공통 기간, 세금, 물가, 고갈 확률, 비중 검증을 손계산 가능한 테스트로 추가했습니다.
- I-5: 비중 합계·날짜 정렬·환율 누락을 검증하고 수익률 누락을 0으로 대체하지 않도록 수정했습니다.
- I-6: 환율 데이터 파싱 실패·빈 데이터·3일 초과 stale 데이터를 오류/경고로 반환하고 홈/API에 표시하도록 수정했습니다.
- I-7: 월말 데이터의 공통 날짜와 동일 환율 기준을 사용하도록 정렬 기준을 명시적으로 통일했습니다.

## 3차 반영

- N-1: 백테스트가 적립금과 분리된 `marketReturn`을 반환하고, 몬테카를로는 이를 부트스트랩하도록 수정했습니다. 0% 시장수익률 + 적립금 회귀 테스트를 추가했습니다.
- N-2: 서버는 ETF별 원시 월 데이터와 환율만 전달하고, 클라이언트가 비중 0% 초과 ETF의 교집합을 다시 계산합니다. 5/10/20년 선택이 실제 기간을 바꾸며, SPYQ 단축 원인과 기본 0% 비중을 표시합니다.
- I-7: 월초 매수 모델로 변경했습니다. 첫 달 원금·적립금은 매수만 하고 다음 달 수익부터 반영하며 테스트로 고정했습니다.
- N-3: 비중 입력을 0~100%로 clamp하고 음수·합계 오류를 차단했습니다. 서버 데이터 변환과 클라이언트 계산을 오류 카드로 감쌌습니다.
- N-4: 현재 나이·은퇴 나이로 계산한 `yearsToRetire`를 FIRE 목표액과 은퇴 후 명목 생활비에 반영했습니다.
- N-5: 나이, 적립금 증가율, 고정환율, 프리셋 3종, 세금 옵션, CAGR, 원금 대비 수익률, 은퇴 후 기간, 원화·달러 Recharts 차트를 추가하고 고정환율 기본값을 최신 일별 환율로 초기화했습니다.
- N-6: SPYQ의 짧은 기간을 기간 열과 안내 문구에 명시하고, 실제 데이터 기반 성과 차트와 기간별 비교 흐름을 연결했습니다.
- N-7: Prettier를 추가하고 `src/` 전체를 포맷했습니다. `npm run format`으로 재현할 수 있습니다.

## 4차 반영

- N-8: CAGR을 적립금과 무관한 월 `marketReturn` 기하평균 연환산으로 변경하고, `연환산 수익률(적립 효과 제외)` 라벨과 초기금 0 안전 처리를 추가했습니다.
- N-9: 연도별 수익률을 전년 12월 기준으로 계산하고, 모든 ETF 연도의 합집합 열·없는 해 `—`·부분연도 `*` 표시를 적용했습니다.
- N-10: 몬테카를로 적립기를 은퇴까지의 `(은퇴 나이 - 현재 나이) × 12`개월로 변경하고, 선택한 과거 백테스트 수익률 풀을 미래 시뮬레이션에 재표집하도록 화면에서 구분했습니다.
- N-11: 안정형·성장형·공격형 프리셋에서 SPYQ를 제외하고 직접 설정 탭을 추가했습니다. 기본 안정형 비중과 탭 표시를 일치시켰습니다.
- N-12: 원화·달러 차트에 보조 Y축을 추가하고, 고정환율·인출률 최소값, 활성 ETF 변환 오류, 세금 단순화 가정, 과거 구간 목표 시점, 홈 환율 경고를 보강했습니다.

## Windows 작업 스케줄러 예시

작업 만들기에서 매일 실행 트리거를 추가하고, 프로그램에 `npm.cmd`, 인수에 `run collect:fx`, 시작 위치에 프로젝트 경로를 지정합니다. 데이터 수집 후 배포 환경에서 `/api/fx`가 최신 저장값을 반환합니다.
